# Summit Economics (economics.doppsclass.com)

Twin of Bedrock (jumpalpha/Bedrock) for Mrs. Bohrer's economics class. Teacher name lives in `src/data/config.ts` only.
- Database: Supabase project `gmeyamrlqfrabtslsweu`, tables/functions prefixed `econ_` (schema in `supabase/schema.sql`).
- Answer keys are never committed (public repo). Content JSON is generated by the private `summit-content/build.py`.
- Internal code still says "realm" for a unit and "tls" for Think Like an Economist; the UI says Unit / Think Like an Economist.
